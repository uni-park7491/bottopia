# BOTTOPIA 배포 전 점검 — 2026-09-12

## 이번 변경
- 프로필 사진, 작품 영상, 커버 이미지 공통 드래그앤드롭 입력. 네이티브 파일 선택과 FormData 유지, 한 파일 제한, 형식·용량 검사, 키보드 접근, 오류 알림, 폼 초기화 반영.
- 프로필 사진 즉시 저장 동작 유지. 중복 사진 업로드 및 작품 중복 제출 방지.
- 비공개 초안 저장 시 공개되었다고 표시하던 안내 수정. 저장 후 목록 갱신 실패를 작품 저장 실패로 오해하지 않도록 수정.
- 크리에이터 카드 폭, 프로필 편집 최대 폭, 제목 크기·줄간격 축소/정리. 모바일에서는 편집 폼을 미리보기보다 먼저 배치.
- 기존 서버 역할을 사용하는 작은 역할 뱃지. 등급·인증·권한 부여 기능 아님.
- MIME sniffing/iframe 삽입 차단, referrer 및 camera/microphone/geolocation 제한 헤더, 제한적인 CSP 추가. 스크립트 전체를 제한하는 완전한 CSP는 아님.
- 업로드 URL/작품 등록의 잘못된 JSON 처리, 일부 내부 DB 오류 메시지 노출 제거, 서명 업로드 토큰 응답 캐시 금지.

## 배포 전에 남은 항목
1. 실제 운영 Supabase RLS/Storage 비공개 정책이 저장소 SQL과 같은지 관리자 화면/DB에서 검증. 이번 검토는 코드 및 로컬 API 중심이며 원격 정책 재검증 아님.
2. 문의/댓글/프로필 사진에 지속적인 서버측 요청 제한 및 스팸 대응 필요. 현재 문의 honeypot/입력 검사는 대량 공격 방어를 대체하지 못함.
3. 다른 회원의 작품 업로드는 현재 운영자 전용. 승인된 크리에이터 업로드를 열려면 소유자별 저장 경로·작성/삭제 권한·회원별 용량/개수 한도·신고/숨김 절차가 먼저 필요.
4. 실제 파일 드롭→Storage 저장→새로고침 후 유지→공개 노출까지 사용자가 지정한 테스트 파일로 검증. 기존 사용자 프로필 사진/작품을 테스트 목적으로 바꾸지 않음.
5. 운영 OAuth 주소와 공급자 활성화, SITE_OWNER_USER_ID, 공개 SITE_URL, 백업·복구 경로 확인. 프로필 편집의 URL 미리보기는 기존 로컬 환경변수 3000을 보여주므로 운영에서는 반드시 https://bottopia.studio 설정.
6. 대량 작품을 대비한 서버 페이지네이션과 미디어 전송량/저장공간 경보. 현재 클라이언트 더보기는 서버 데이터 페이지네이션이 아님.
7. 계정 2FA·복구 코드 보관, 과거 외부에 공유한 인증 설정 QR/키가 있다면 재발급 여부 확인. 비밀값을 저장소에 커밋하지 않기.

## 제품 피드백
포트폴리오와 공개 제작 노트를 보여주는 소규모 베타로는 방향이 명확해졌다. 보라·라임 포인트와 컴팩트한 영상 피드가 브랜드를 유지한다. 다만 모든 사람이 업로드하는 커뮤니티라고 홍보하기에는 권한·운영 도구가 아직 부족하다. 처음에는 소수 승인 크리에이터로 운영하고 실제 작품/과정/협업 사례를 쌓는 편이 좋다. 뱃지는 인기 순위보다 초기 참여와 실제 기여를 표현하고, 나중에 리믹스 공유·협업 참여 같은 활동 표식을 검토한다.

이번 변경은 로컬 작업 트리에만 있으며 커밋·푸시·운영 배포하지 않았다.
