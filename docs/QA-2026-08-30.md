# 로그인 추가·오류 점검 결과 (2026-08-30)

검수 대상: 로컬 Next.js 프로젝트. Supabase 및 외부 로그인 앱 자격 증명은 설정되지 않은 상태입니다. 운영 사이트 배포 또는 실제 계정 인증 완료를 의미하지 않습니다.

## 통과

- `npm test`: 32개. 제공자 순서/식별자, OAuth 콜백 인자, 복귀 경로 검증, 로컬 호스트 보존, 운영 환경 HTTPS 주소 검사, 운영자 UUID/확인된 이메일 권한 정책.
- `node tests/local-smoke.mjs`: 18개. 공개 페이지, 4개 언어, 설정 없는 로그인/콜백, 잘못된 복귀 주소, 로그인 없는 업로드·댓글·삭제 차단, 설정 없는 복사 API 응답.
- `npm run lint`, `npm run build`, `git diff --check` 통과.
- `npm audit --omit=dev`: 운영 의존성에 보고된 취약점 0개. 보안 취약점이 전혀 없다는 보증은 아닙니다.
- 실제 브라우저: 홈 → 로그인 진입, 4개 언어 전환, 미설정 버튼 비활성화, 실패 안내, 홈 복귀. 검수 중 콘솔 error 0건. 좁은 화면에서 수평 넘침 없음.

## 수정한 문제

- 이메일 없는 회원 + 운영자 이메일 설정 누락 조합이 업로드 API의 운영자 검사에서 일치하던 문제. UUID 우선, 확인된 이메일 보조, 누락 시 차단으로 변경.
- `/\\...` 형태의 외부 복귀 URL 및 인코딩 변형. 로컬/운영 콜백 주소 검증 추가.
- Next dev의 localhost 정규화로 127.0.0.1에서 시작한 인증이 다른 호스트로 돌아가던 문제.
- 로그인 서비스 미설정·코드 교환 실패 시 500 오류 또는 설명 없는 홈 이동. 안전한 재시도 페이지로 변경.
- 로그인·로그아웃의 예외 처리, 이메일 없는 회원 표시, 세션 쿠키 갱신.
- 댓글 등록 실패에도 입력창을 지우던 동작, 댓글 삭제 오류 누락, 비공개 작품 댓글 조회 노출, DB 조회 오류 누락.
- 작품 로딩 실패를 빈 목록처럼 표시하던 문제, 클립보드 실패에도 성공으로 표시하던 문제.
- 복사 횟수 API의 미설정 오류·없는 작품 처리·동시 증가 덮어쓰기.
- 프롬프트 메뉴가 오리지널 랩에서 아카이브로 전환하지 않던 문제 및 Next.js 스크롤 경고.

## 아직 검증하지 못한 부분

- 실제 Google·네이버·카카오 동의 화면, 토큰 교환, 신규 가입/재로그인, 실제 세션 갱신/로그아웃.
- 실제 DB 및 Storage를 사용하는 운영자 업로드, 댓글·좋아요·삭제, 복사 횟수 동시 업데이트.
- 공개 배포 호스트·커스텀 도메인 및 각 제공자 앱의 외부 사용자 이용 승인 상태.

위 기능은 [소셜 로그인 설정 안내](SOCIAL_LOGIN.md)의 외부 설정과 실제 계정 검수가 끝난 뒤 활성화해야 합니다. 테스트용 작품이나 가짜 회원은 추가하지 않았습니다. 이번 작업은 로컬 파일 변경이며 GitHub push/외부 배포는 실행하지 않았습니다.
