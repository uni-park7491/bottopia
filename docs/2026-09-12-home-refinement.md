# BOTTOPIA 홈페이지 개선 — 2026-09-12

## 방향
브랜드 소개보다 작품 탐색을 먼저 제공한다. BOTTOPIA의 포트폴리오는 유지하되, 회원 작품과 제작 과정을 담을 수 있는 작은 카드 피드로 정리한다.
- AtlasCloud: 검색/분류/영상/프롬프트를 가까이 배치. 실제 참고 페이지를 브라우저에서 확인.
- SAVEE: 작품이 중심이 되는 절제된 화면을 참고.
- Cosmos: 작품에서 창작자와 출처로 이어지는 관계를 참고.
- Xazinga: 이번 실행에서 원격 페이지 연결 실패. 현재 화면을 다시 확인했다고 주장하지 않음.

## 구현
- 홈 대표 영상을 별도 대형 영역으로 노출하지 않고 모든 작품을 같은 카드로 표시.
- 데스크톱 3열(1600px 이상 4열), 태블릿·모바일 2열. 전체 화면은 작품 상세에서 감상.
- 검색(제목/소개/도구/모델/창작자), 분류, 최신순/복사순, 24개씩 표시.
- 오리지널 별도 메뉴 제거. 기존 /original 링크는 작품 피드의 originals 필터로 이동.
- 오리지널 정의: ORIGINAL 작품이며 founding creator의 작품. 기존 창작자 미연결 작품은 운영자 작성 데이터이므로 포함.
- 루트 레이아웃의 공통 헤더로 메뉴 위치·순서·언어 유지.
- 제목/본문/보조텍스트 크기와 행간 조정. 보라색 포인트와 밝은 중립 배경.
- 프로필 사진: 브라우저 512px 변환 → 인증된 API → 서버 재검사/재인코딩 → 비공개 works 버킷의 본인 전용 경로.
- 승인된 공개 프로필의 사진만 공개 API로 제공. 본인은 인증된 사진 API로 미리보기.
- 기존 SNS 링크 편집/새 탭 이동 유지, 프로필 화면의 글자 크기 조정.
- 가까운 영상만 로드, 포스터가 있으면 영상 사전 다운로드하지 않음. 화면 밖 영상 일시정지.
- 공개 미디어마다 수행하던 불필요한 프록시 인증 갱신 제거. 보호된 API의 자체 권한검사는 유지.
- 공개 피드 목록만 짧은 CDN 캐시 사용. 운영자 전체목록은 비공개/no-store 유지.
- 문의 저장 뒤 비동기 이벤트 참조로 실패 안내가 뜰 수 있던 부분 수정.
- Next.js 16.3.3, sharp 0.35.4 및 js-yaml 보안 패치. npm 검사 0 vulnerabilities.

## 검증
- 단위/소스 회귀 테스트 52개 통과.
- ESLint, Next production build 통과.
- Chrome 데스크톱 및 390px 모바일에서 실제 공개 작품 2개 카드, 검색 빈 결과/초기화, 메뉴 이동, 언어 유지, 공개 프로필/인스타그램 링크 확인.
- 인증 없이 프로필사진 POST/영상 업로드 URL POST 요청이 401로 거부됨.
- 사진의 실제 계정 저장 왕복 테스트는 아직 수행하지 않음. 사용자 사진이나 테스트 작품을 운영 데이터에 업로드하지 않음.
- Chrome 확장 프로그램이 html에 속성을 추가해서 발생하는 개발모드 hydration 경고는 관찰했으나 앱 코드로 숨기지 않음.
- 개선 속도의 실사용 백분율/점수는 아직 측정하지 않음.

## 비용/배포 및 남은 사항
- 로컬 미리보기: http://127.0.0.1:3001/
- 공개 도메인에 아직 배포하지 않음.
- Supabase Free의 파일당 50MB 제한 유지. 더 큰 파일에는 플랜/저장소 변경과 서버·버킷 제한 동시 조정이 필요. 유료 변경 없음.
- 영상 원본 파일 자체의 압축/트랜스코딩은 이번 작업에 포함하지 않음.
- 다른 회원의 작품 업로드는 현재 운영자 전용 정책 그대로. 실제 크루 업로드를 열려면 승인/신고/저장용량 정책과 권한 검증을 별도로 구현해야 함.
- 이번 사진 업로드는 기존 버킷과 프로필 테이블을 사용하므로 새 SQL 마이그레이션 없음.
