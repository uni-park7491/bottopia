# PC 연결기 삭제 안내 · Mac / Windows

ZIP이나 실행 파일만 지우면 설치한 실행 환경과 모델 파일은 남습니다. 아래 항목을 구분해 삭제하세요. 이 안내서는 자동으로 파일을 삭제하지 않습니다.

## 1. 생성 중단과 연결 해제

필요한 WAV·MP3를 먼저 저장하고 홈페이지에서 **생성 중단**을 누릅니다. 연결기 터미널에서 **Ctrl+C**로 종료한 뒤 터미널 창을 닫으세요. 홈페이지의 **연결 해제 · 저장 삭제**를 누르면 브라우저의 연결 코드도 지워집니다.

## 2. 설치한 모델 실행 환경 삭제

| 운영체제 | 폴더 여는 방법 | 기본 설치 위치 |
| --- | --- | --- |
| Mac | Finder → 이동 → 폴더로 이동(Shift+Command+G) | `~/.bottopia-tts` |
| Windows | 파일 탐색기 주소 표시줄에 입력 | `%USERPROFILE%\.bottopia-tts` |

- 특정 모델만 삭제: 위 폴더 **안의** `qwen-custom` 또는 `qwen-design`처럼 삭제하려는 모델 ID 폴더만 휴지통으로 옮깁니다. 해당 가상환경과 그 안의 실행 패키지가 제거됩니다.
- 모든 BOTTOPIA PC 모델 환경 삭제: `.bottopia-tts` 폴더를 휴지통으로 옮깁니다. 내부에 직접 넣은 체크포인트·설정·음성이 있다면 먼저 백업하세요.
- `BOTTOPIA_TTS_HOME`을 직접 설정했다면 기본 위치가 아닌 그 위치를 확인하세요. 사용자 홈 폴더 자체를 삭제하면 안 됩니다.

## 3. Qwen 모델 파일 삭제 (큰 용량 회수)

실행 환경과 별도로 Hugging Face 캐시에 저장됩니다. 기본 위치는 아래와 같습니다.

- Mac: Finder의 ‘폴더로 이동’에 `~/.cache/huggingface/hub` 입력
- Windows: 파일 탐색기 주소 표시줄에 `%USERPROFILE%\.cache\huggingface\hub` 입력

위 위치에서 삭제하려는 모델과 정확히 일치하는 폴더만 휴지통으로 옮기세요.

- CustomVoice: `models--Qwen--Qwen3-TTS-12Hz-1.7B-CustomVoice`
- VoiceDesign: `models--Qwen--Qwen3-TTS-12Hz-1.7B-VoiceDesign`

다른 앱도 같은 모델 캐시를 사용할 수 있습니다. 삭제하면 다른 앱에서도 다시 다운로드해야 할 수 있습니다. `.cache`, `huggingface`, `hub` 폴더 전체를 일괄 삭제하지 마세요. `HF_HOME`, `HF_HUB_CACHE`, `XDG_CACHE_HOME`을 설정한 경우 캐시 위치가 달라질 수 있습니다. 설치된 모델 환경을 삭제하기 전에 Mac에서는 해당 환경의 `bin/python`, Windows에서는 `Scripts\python.exe`에 `-c "from huggingface_hub import constants; print(constants.HF_HUB_CACHE)"`를 실행하면 실제 위치를 확인할 수 있습니다.

다른 모델의 캐시는 모델별로 다릅니다. 위 두 폴더는 Qwen 전용이며 다른 모델까지 전부 지우는 절차는 아닙니다. Python 패키지 다운로드 캐시도 별도로 남을 수 있지만 다른 프로젝트와 공유하므로 이 안내에서 일괄 삭제하지 않습니다.

## 4. 연결기 파일과 남은 자료

- 다운로드한 ZIP과 압축을 푼 `bottopia-qwen-source` 또는 `bottopia-tts-connector` 폴더를 휴지통으로 옮깁니다. 본인이 이름을 바꿨다면 실제 다운로드 폴더를 확인하세요.
- 따로 받은 `BOTTOPIA Connector.app`이 있다면 종료 후 해당 앱도 휴지통으로 옮깁니다.
- 임시 작업 결과·진단 로그는 운영체제 임시 폴더의 `bottopia-tts-`로 시작하는 작업 폴더에 남을 수 있습니다. 터미널에 출력된 `log:` 경로로 해당 작업 폴더를 확인하고 연결기 종료 후 그 폴더만 지우세요. 임시 폴더 전체를 삭제하지 마세요.
- 따로 저장한 WAV·MP3는 자동으로 지워지지 않습니다. 필요 없는 파일만 직접 삭제하세요.
- 브라우저의 BOTTOPIA **사이트 데이터 삭제**는 연결 코드·생성 시간 기록·브라우저 모델 캐시뿐 아니라 로그인과 로컬 작업 데이터도 지울 수 있습니다. 필요한 작업을 먼저 내보내세요. PC 모델 파일은 사이트 데이터를 삭제해도 남습니다.
- Python·Git·SoX 등 공용 도구는 다른 앱이 사용할 수 있으므로 이 과정에서 삭제하지 않습니다.

휴지통에 있는 동안은 복원할 수 있습니다. 용량을 실제로 회수하려고 휴지통을 비우면 복구가 어려워지므로 대상 파일을 확인하세요. 다시 사용하려면 연결기를 내려받고 모델을 재설치하면 됩니다.
